## Installation
1. Clonez le dépôt : `git clone https://github.com/HAYET-MEDINI/E-commerce-Laravel-Project`
2. Installez les dépendances : `composer install`
3. Copiez `.env.example` vers `.env` : `cp .env.example .env`
4. Configurez la base de données dans `.env`
5. Exécutez les migrations : `php artisan migrate`
6. (Optionnel) Exécutez les seeders : `php artisan db:seed`
